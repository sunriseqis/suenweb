# 设计系统：Maximalism / Dopamine（本项目正式采用）

> 历史存档：本文件是 v1 的 Maximalism / Dopamine 设计系统，已于 M2 迭代 4 被 Metro 磁贴风格替换（见 DESIGN-SYSTEM.md）。仅作参考，不再执行。

> 来源：用户提供的设计系统提示词。本文件是它在 SuenWeb 2.0 的「落地版」：保留全部视觉规则，替换掉不适配本项目技术栈与部署环境的部分（React/shadcn → 原生 DOM 变体表；emoji 装饰 → 几何图形与 SVG 图标）。

## 一、设计哲学

**核心原则：MORE IS MORE。** 拒绝极简克制，追求令人愉悦的视觉过载：图案互相冲突、颜色喊叫、元素刻意重叠。空的空间就是浪费的空间。

**情绪目标**：欣快、俏皮、Y2K 与 Gen-Z 混血的 hyperpop 气质。判断标准一句话——**「它是否以一种让人开心的方式视觉过载？」如果答案是否，就再加一点。**

**本项目唯一例外**：书签主界面是高频工具界面，长期注视需要控制疲劳。因此约定「两级动效强度」（见第六章），满功率只用在登录、引导、设置这些低频页面。

## 二、色彩令牌

### 2.1 深色（默认，设计原稿值）

| 令牌 | 值 | 用途 |
|---|---|---|
| --c-bg | #0D0D1A | 深空紫黑底，让一切发光 |
| --c-fg | #FFFFFF | 正文与标题（对比度 19.5:1，AAA） |
| --c-muted | #2D1B4E | 半透明容器、卡片底 |
| --c-border | #FF3AF2 | 默认边框色（热洋红） |
| --c-accent | #FF3AF2 | 主强调：洋红 |
| --c-secondary | #00F5D4 | 次强调：电青 |
| --c-tertiary | #FFE600 | 三强调：尖叫黄 |
| --c-quaternary | #FF6B35 | 四强调：电橙 |
| --c-quinary | #7B2FFF | 五强调：荧光紫 |

### 2.2 浅色（本项目补充，同一套五色加深保对比）

| 令牌 | 值 | 说明 |
|---|---|---|
| --c-bg | #FFF7EE | 奶油白底（不是纯白，保留暖意） |
| --c-fg | #170F2B | 深茄紫近黑，正文 15:1 |
| --c-muted | #F4E6FF | 浅紫容器底 |
| --c-border | #C4179E | 洋红加深，奶油底上可读 |
| --c-accent | #C4179E | 洋红加深 |
| --c-secondary | #00907C | 电青加深 |
| --c-tertiary | #A87900 | 尖叫黄加深（奶油底上唯一可读的黄） |
| --c-quaternary | #C64A16 | 电橙加深 |
| --c-quinary | #6320D0 | 荧光紫加深 |

浅色**不降级**：撞色边框、多层硬阴影、图案层、微旋转全部保留，只换配色。装饰用的高饱和亮色（如亮黄 #FFE600 色块）仍可出现，但块上的文字必须是深色（#170F2B）。

### 2.3 用色规则

- **五色轮转**：区块按索引 % 5 轮转主色，相邻区块不得同色。
- **撞色**：边框颜色必须与背景冲突（洋红底配黄或青边框），永远不用中性色边框。
- **强调色不做正文**：强调色只用于装饰、标签、图标；正文只用 --c-fg。
- **对比度**：正文必须 AAA；强调色块上的文字按「深底白字 / 亮底深字」选择。

## 三、排版

| 角色 | 字体 | 说明 |
|---|---|---|
| 标题 | Outfit（700-900） | 几何无衬线，拉丁字形 |
| 正文 | DM Sans（400-700） | 混乱中的可读性 |
| 展示 | Bungee | 仅用于特殊喊话、按钮徽标，节制使用 |
| 中文回退 | 系统黑体（PingFang SC / 微软雅黑 / 思源黑体） | 不额外加载中文字体文件 |

**字号**（激进尺度）：主标题 72-128px、区块标题 48-72px、子标题 24-30px、正文 18-20px、小字 14-16px。

**排版规则**：标题用 800-900 字重 + `tracking-tight` + `leading-none`；标签用 `tracking-widest` + 大写；正文 `leading-relaxed`；英文标题全大写。

**文字阴影**（本项目中文做了妥协）：

- 英文/数字标题：三层堆叠 `2px 2px 紫, 4px 4px 洋红, 6px 6px 青`；Hero 用四层 mega 堆叠（4/8/12px）。
- **中文标题：只允许单层 1px 阴影或纯色实心描边**。三层阴影会让汉字糊成一团，这是可读性红线。
- 渐变文字：`linear-gradient(90deg, 洋红, 青, 黄, 洋红)` + `background-clip: text` + 4s 位移动画，只用在 20-30% 的标题上。

## 四、边框、圆角、阴影

- 边框默认 4px（`border-4`），区块分隔与重点元素用 8px；2px 只用于内部细分隔线。
- 同一区块内混用 2-3 种边框样式（实线 + 虚线 + 双线），但要有主次，不要平均。
- 圆角：按钮全圆角（pill）、卡片 24px、容器 16px；允许四角不同半径制造不对称。
- **阴影至少两层**：软发光（彩色、大范围）+ 硬阴影（偏移、纯色）。硬阴影按 8→16→32px 倍增偏移，每层不同强调色。
- Hover 时增加层数或强度，不允许只换颜色。

## 五、图案与纹理（强制分层）

每个区块至少 2 层图案：

| 图案 | 实现 | 透明度 |
|---|---|---|
| 点阵 | `radial-gradient(circle, 强调色 1px, transparent 1px) / 20px` | 0.15-0.3 |
| 斜条纹 | `repeating-linear-gradient(45deg, transparent 10px, 强调色 10px 20px)` | 0.05-0.1 |
| 棋盘 | `conic-gradient(from 90deg at 1px 1px, transparent 90deg, 强调色 0)` | 0.03-0.07 |
| 渐变网格 | 2-4 个错位 `radial-gradient` 椭圆 | 0.1-0.2 |

实现方式：伪元素 + `pointer-events: none`，部分层用 `mix-blend-mode` 融合。全局 2 层固定图案 + 每区块 1-2 层专属图案。

## 五之二、项目定制的三条硬规则

1. **按下不抹阴影**：`active` 只把位移与阴影收一层（3px / 6px），绝不出现 `shadow-none`，否则选中/按下会与整体割裂。选中态（分组 pill、主题按钮）必须保留小号多层阴影。
2. **编辑模式是锁**：页面级操作只放在右下角自动隐藏胶囊里；胶囊的编辑按钮是锁状开关，锁住＝只读（无拖动、无增删改），解锁＝可拖动可编辑。
3. **密度优先**：书签是高频浏览界面，卡片比宣传页更紧凑（padding 16px、圆角 20px、阴影 5/10px、桌面最多 5 列），满功率的夸张只留给登录与设置页。
4. **色彩预算（内容区）**：高频浏览页一页只允许一个主色系——按组轮转的强调色只出现在组标题圆点、选中态、hover 与置顶区边框上；链接卡片/行/胶囊一律中性（`border-fg/10~15`、无彩色硬阴影、无每卡图案）。撞色边框与多层阴影属于「少量元素」的特权，不属于列表。

## 六、动效（两级强度，本项目关键约定）

| 级别 | 用在哪 | 内容 |
|---|---|---|
| **满功率** | 登录、首设密码、引导、设置页 | 漂浮几何装饰、渐变流光标题、巨型背景字、脉冲发光、慢速旋转 |
| **半功率** | 书签主界面（高频） | 撞色边框、多层阴影、图案层、微旋转全部保留；**持续动画只放在装饰层**（页面角落、空状态插图），内容卡片只在 hover/focus 时动 |

**降噪模式**：界面提供「降噪模式」开关（持久化在本地），开启后停掉所有持续动画，仅保留 hover/active 过渡；同时始终尊重 `prefers-reduced-motion: reduce`。

动画时序：微交互 100-300ms，卡片 300-500ms，漂浮 5-8s，流光 4s，慢旋转 20s。缓动默认 `ease-out`，活泼场景用 `cubic-bezier(0.68, -0.55, 0.265, 1.55)`。只用 `transform` 与 `opacity`。

## 七、标志性元素（Bold Factor 清单）

1. 漂浮几何装饰：星形、闪光、圆环、方块，尺寸从 24px 到 96px 不等，绝对定位，缓慢漂浮或摆动。
2. 巨型背景文字：`12rem`-`20rem`，`opacity 0.2`，溢出边缘，用于区块底部。
3. 图案叠图案：每区块至少两层。
4. 系统性换色：区块与网格项按索引轮转五色。
5. 撞色边框：边框永远与背景冲突。
6. 多层阴影：发光 + 硬阴影叠加。
7. 不对称布局：同一行元素垂直错位、旋转角度不同、允许轻微斜切。
8. 混合边框样式：同区块 2-3 种。
9. **装饰图形替代 emoji**（本项目铁律）：设计原稿用 emoji 撒点，本项目一律换成内联 SVG 几何图标，尺寸、颜色、动画一致。
10. 动态渐变标题：20-30% 的标题使用。

## 八、禁止事项（违反即破坏风格）

1. 中性/灰边框；2. 单层阴影；3. 完全对称的网格；4. 空背景区块；5. 小字号标题；6. 单色方案；7. 只有颜色变化的 hover；8. 1-2px 细边框；9. 克制按钮；10. 标题无文字阴影；11. 边框与背景同色；12. 大量静态元素；13. **任何 emoji**。

## 九、可访问性（硬要求）

- 正文对比度 AAA；强调色不承载关键信息。
- 焦点态双环：`outline 4px A色 + offset 4px B色`，总厚度不少于 8px，且不允许只靠颜色区分。
- 所有交互元素键盘可达，最小触摸目标 44x44。
- 装饰元素 `aria-hidden="true"`；图案是纯 CSS 背景，不进可访问性树。
- `prefers-reduced-motion: reduce` 时停掉关键帧动画，过渡缩短到 150ms。

## 十、在本项目的技术映射

| 设计要求 | 本项目实现 |
|---|---|
| React + shadcn + CVA | 原生 DOM 渲染函数 + 类名变体表（`buttonClass({ variant, size })`）+ `cn()` |
| Tailwind v4 任意值 | Tailwind v4 + CSS 变量令牌，颜色永不硬编码在组件里 |
| Lucide React | 内联 SVG symbol 精灵（零运行时依赖，离线可用） |
| emoji 装饰 | 内联 SVG 几何图形 |
| Google Fonts CDN | `@fontsource` 自托管 woff2（仅拉丁子集），内网可用 |
