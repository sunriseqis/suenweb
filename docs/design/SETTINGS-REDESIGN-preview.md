## Tab 2 · 数据

### 卡片 ① 书签 —— 两个按钮

    [ 导入 ]   [ 导出 ]
- 导入 →【弹窗】选文件 → 预览统计 → 确认导入
- 导出 → 直接下载 Netscape HTML（无弹窗）

### 卡片 ② 配置 —— 两个按钮

    [ 导入 ]   [ 导出 ]
- 导出 →【弹窗】输管理密码 → 下载 .swb1
- 导入 →【弹窗】选 .swb1 → 输管理密码 → 覆盖范围预览 → 二次确认

### 卡片 ③ 链接 —— 两个按钮

    [ 检查重复 ]   [ 检查失效 ]
- 检查重复 →【弹窗】聚类列表（跨组同 URL + 分组归属）→ 逐簇「保留首条删其余」
- 检查失效 →【弹窗】检测进度 → 结果列表（状态码 + 分组 + 标题）→ 「删除全部失效项」

### 卡片 ④ 备份 —— 状态内联 + 四个按钮

    已配置 http://dav.example.com · 保留 30 份 · 上次备份 10-27 09:30    ← 内联状态行
    （或「未配置 WebDAV：不执行任何自动备份」）

    [ 配置 ]   [ 立即备份 ]
    [ 备份 ]   [ 还原 ]
- 配置 →【弹窗】地址 / 用户名 / 密码 / 保留份数 / 管理密码 五框全进弹窗，页面零输入框 → 保存并测试
- 立即备份 → 按钮直接执行，toast 显示上传文件与大小
- 备份 →【弹窗】远端备份列表（名称 / 大小 / 时间）+ 选中 + 输管理密码还原（查看与还原合并在同一弹窗内完成）

## 实现要点

1. 路由：#/settings 单页两 Tab（通用 / 数据），hash 记忆；旧 #/data 跳转兼容到数据 Tab
2. 左侧垂直 Tab（宽屏） / 顶部横滚条（<640px），当前 Tab 强调色高亮
3. 弹窗走现有 overlay 体系（Metro 面板）；「检查重复」「检查失效」抽独立函数
4. 胶囊入口合并：右下角只剩「登录（游客）/ 编辑锁 · 设置 · 登出（登录）」，「数据」入口取消
5. 页面消失的输入框：14 个（文件×2、密码×5、域名×1、WebDAV×4、改密×2），全部进弹窗
6. 卡片统计：通用 4 张 + 数据 4 张 = 8 张
