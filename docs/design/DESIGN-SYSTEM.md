# 设计系统：Metro / 磁贴（当前生效）

> 版本 v2，替换掉 v1 的 Maximalism / Dopamine（原稿存档在 DESIGN-SYSTEM-dopamine.md，仅作历史参考，不再执行）。
> 理由：书签是高频浏览工具，一条链接一个颜色会让 90+ 条规模下整页花掉，识别成本高于个性收益。

## 一、原则

1. **内容优先**：界面是容器，书签是内容。装饰不得抢内容的注意力。
2. **单一强调色**：全站只有一个强调色（Metro 蓝），承担「可交互 / 选中 / 当前」三种语义。颜色是信息，不是装饰。
3. **直角与细线**：0 圆角、1px 描边、无阴影、无渐变、无纹理。层级用底色深浅与线宽表达。
4. **磁贴即入口**：链接就是一块磁贴，大小由分组密度决定（方 / 行 / 宽），不做卡片式包装（无头像、无多层投影）。
5. **空即是留白**：留白是节奏，不是浪费。禁止满屏装饰。

## 二、色彩令牌（web/src/styles/tokens.css 是唯一真源）

| 令牌 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| --c-bg | #141414 | #f3f3f3 | 页面底 |
| --c-surface | #1f1f1f | #ffffff | 磁贴 / 面板 |
| --c-surface-2 | #262626 | #ececec | 次级底（悬停、分组容器） |
| --c-fg | #f2f2f2 | #1b1b1b | 正文与标题 |
| --c-fg-soft | rgba(242,242,242,.6) | rgba(27,27,27,.6) | 次要信息、标签 |
| --c-line | rgba(255,255,255,.14) | rgba(0,0,0,.12) | 1px 描边 |
| --c-line-strong | rgba(255,255,255,.3) | rgba(0,0,0,.3) | 强调描边、虚线占位 |
| --c-accent | #1ba1e2 | #0b6fa4 | 唯一强调色 |
| --c-accent-soft | rgba(27,161,226,.16) | rgba(11,111,164,.1) | 悬停底色 |
| --c-accent-active | rgba(27,161,226,.3) | rgba(11,111,164,.2) | 按下底色 |

规则：强调色只用于「可交互、选中、当前」；不给纯装饰元素上色；正文永不使用强调色。对比度正文 ≥ 7:1，次要文字 ≥ 4.5:1。

## 三、排版

| 角色 | 字体 | 规格 |
|---|---|---|
| 页面标题 | Outfit 300 | 22px，行高 1.1 |
| 分区标题 | Outfit 600 | 13px，大写，字距 0.1em |
| 磁贴标题 | DM Sans 600 | 13px（方磁贴 11px），最多 2-3 行截断 |
| 次要信息 | DM Sans 400 | 10px，大写，字距 0.08em，--c-fg-soft |
| 正文 | DM Sans 400 | 15px，行高 1.55 |

不用文字阴影、不用渐变文字、不用描边字。大写只用于标签与按钮，正文不强制大写。

## 四、磁贴系统

| 尺寸 | 网格 | 内含 | 适用 |
|---|---|---|---|
| 方磁贴 | `minmax(88px, 1fr)`，正方形 | 标题 2-3 行居中 | 链接多、只认名字的分组 |
| 行磁贴 | `minmax(210px, 1fr)`，高 36px | 标题 + 域名 | 中等数量、要读域名的分组 |
| 宽磁贴 | `minmax(190px, 1fr)`，高 ≥ 92px | 标题（2 行）+ 域名 + 一行备注 | 置顶组、重点分组 |

交互态：

- 悬停：底色 → --c-accent-soft，边框 → --c-line-strong，左侧 2px 强调条亮起。
- 按下：底色 → --c-accent-active，整体下沉 1px，不出现阴影。
- 焦点：2px 强调色 outline，偏移 2px。
- 编辑模式：磁贴右上角浮现编辑 / 删除（宽磁贴另有上移下移），可拖拽排序；只读模式不出现任何编辑元件。

## 五、分区与导航

- 分区标题：2.5px 见方强调色方块 + 大写组名 + 数量 +（置顶区）pinned 标记。
- 置顶区：浅底容器（--c-surface-2）包住，内部磁贴同规格，靠位置而非颜色区分层级。
- 分组导航：一条横向可滚动的文字按钮，选中项用强调色填充。

## 六、动效

只有两档：110-160ms 的底色/边框过渡，与 200ms 的胶囊收放。没有漂浮、脉冲、渐变流动、旋转。`prefers-reduced-motion` 时过渡降到 60ms。

## 七、禁止事项

1. 一条链接一种颜色（色彩预算违规）。2. 圆角超过 0（除胶囊形的导航按钮）。3. 阴影、发光、渐变、纹理、噪点。4. 倾斜、旋转、错位摆放。5. 巨型背景文字与装饰 emoji。6. 多层描边（>1px，焦点环除外）。7. 用强调色写正文。8. 常驻动画。

## 八、可访问性

- 正文对比度 ≥ 7:1；次要信息 ≥ 4.5:1；强调色块上的文字用 --c-accent-ink。
- 焦点环 2px 且不与背景同色，键盘可达全部操作；触摸目标 ≥ 32px（胶囊按钮 32px，磁贴整块可点）。
- 磁贴是可点击区域，标题即链接文本；分组标题用 h2，页面标题用 h1。
- 装饰性色块 `aria-hidden`，不参与朗读。

## 九、技术映射

| 设计 | 实现 |
|---|---|
| 令牌 | tokens.css 的 `--c-*` + `@theme` 映射（bg / surface / surface2 / fg / line / accent / ink） |
| 磁贴 | `ui/surfaces.ts` 的 `tile()` + app.css 的 `.tile` / `.tile-mark` |
| 面板 | `card()`：1px 描边 + surface 底，无阴影 |
| 按钮 | `ui/button.ts` 五个变体：primary（强调色填充）/ secondary（细边）/ outline / ghost / icon |
| 图标 | `ui/icons.ts` 内联 SVG，线宽 1.8 |
| 强调色语义 | 只出现在可交互状态，见第四节 |

## 十、页面搜索与分组切换

搜索框就是**网页搜索**，不是书签过滤：左侧引擎下拉（Google / Bing / DuckDuckGo / Brave / Startpage / Mojeek / Qwant），右侧输入框，回车在新标签打开；引擎选择存本地（`sw.engine`），默认 Google。页内找书签用浏览器原生查找。

分组不切页：置顶组固定在最上方独立成块，不参与 tab；普通组在下方共用一条 sticky tab 条，点击滚动到对应分组、滚动时联动高亮，**内容全程保持展开**（tab 是定位工具，不是内容容器）。

## 十一、布局外壳

- 应用外壳固定视口高度（100dvh）：顶部 app bar 不滚动，中间内容区独立滚动，页面永远有底，不会随内容无限向下延伸。
- 顶栏不放页面标题：只有居中拉长的网页搜索框（max 42rem）与右侧编辑操作；默认引擎在设置页固定，搜索框内可临时切换。
- 置顶组常驻顶部区块；普通组是真 tab —— 只渲染当前选中的分组，其余不占空间。
