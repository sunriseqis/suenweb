# SuenWeb 2.0 · 功能清单（重构基线 v1.6）

> 用途：本项目重建后的**唯一功能参照**。开发任务、提交、PR、验收一律引用本文的功能 ID。
> 版本：v1.6（全部决策已裁定，见第零章「裁决记录」；本地部署 + 低阻塞架构，详见 [ARCHITECTURE.md](./ARCHITECTURE.md)）
> 变更摘要：访客只读、分组名唯一且重名自动合并、Firefox 为主力、外观个性化后置、AI 能力移除、备份口令复用管理密码且仅在有 WebDAV 时启用；**放弃 Cloudflare Workers，改本地部署（Docker + fnOS 原生包），开发期一律 npm 启动**；v1.6 追加：密码最短 6 位、链接去重同组静默 / 跨组弹窗确认（用户忽略后不再提示）。

| 25 | 顶栏无标题 + 默认引擎在设置 | 顶栏不显示页面标题，只保留居中搜索框与右侧操作；**默认搜索引擎在「设置」里固定**（7 选 1，写到本机 `sw.engine`），搜索框内的下拉仍可临时切换并记住 |
| 26 | 站点图标抓取 | **默认关闭**：不开时磁贴只显示文字、服务端不出网；在设置页开启后按域名取 favicon（GET /api/icon?domain=），缓存到 data/icons/（30 天、200KB 上限、6s 超时）。**访客只读缓存**，抓取只由已登录用户的请求触发，避免被当作 SSRF 跳板；取不到就静默回退纯文字磁贴 |
| 27 | 置顶分栏 / 图标缓存 / 磁贴尺寸 | **置顶组自动分栏**（参照旧版）：`layout_mode=single` 独占一行，其余按 3 列打包进网格（4 个时拆成 2+2），每组可在编辑模式下切换单列/并排。**图标缓存参照旧版**：多源回退（https favicon.ico → apple-touch-icon → http favicon.ico → DuckDuckGo 图标代理）、拒绝 text/html、命中缓存 30 天、全部失败写 1 天负缓存。**磁贴放大**：方 116px、行 40px、宽 232px×104px，标题 12-14px、域名 10-11px |

## 一、产品定义

**一句话**：自托管的书签服务。书签存在自己的服务端，浏览器插件负责「一键收藏」，导航页负责「多端浏览」，加密备份与导入导出负责「不丢数据、不泄露」。

**核心闭环（P0 必须全部打通）**

    浏览器右键/一键 ──► 插件 ──► 服务端书签库 ──► 导航页浏览（访客只读）
                                      │
                                      ├──► 导入（浏览器书签 HTML / JSON；加密文件需管理密码解密）
                                      ├──► 导出（HTML / 加密 JSON）
                                      └──► 备份（管理密码派生密钥加密后上传 WebDAV，本地 /data 亦可）

**边界**：单用户、**本地自部署**（Docker 镜像 或 fnOS 应用包 .fpk）；不含多用户、不含 AI、不含外观主题系统（首版）、不再提供云端托管形态。

**部署与开发形态（追加裁定，见裁决 12~14）**

| 场景 | 形态 |
|---|---|
| 开发与全部测试环境 | **npm run dev**（唯一验收路径，开发期不投入 Docker） |
| 生产 · 通用自托管 | Docker 镜像 + docker compose，数据卷 /data |
| 生产 · 飞牛 NAS | **fnOS 原生应用包**（原生进程直接运行，非 Docker 转包） |

**技术架构**：以「并发阻塞更小」为准绳重构（Node.js 22 + Fastify + SQLite/WAL 异步驱动 + worker_threads + 进程内调度），完整选型与 8 条低阻塞铁律见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 三、功能清单（55 项）

### A. 服务端书签核心（NAV / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| NAV-01 | 分组管理 | 新建/重命名/删除；类型 fixed（固定区常驻）与 tab（标签区切换）；删组级联删链接 | **分组名唯一**（服务端约束）；同名创建/同名导入自动合并到已有分组；删组后其链接不可通过任何接口取回 |
| NAV-02 | 链接管理 | 新建/编辑/删除：标题、URL、描述、图标、所属分组 | 标题+URL 必填校验；非白名单协议（javascript: 等）被拒；编辑后列表即时反映 |
| NAV-03 | 排序与跨组移动 | 分组排序、组内链接排序、链接拖到另一分组 | 拖拽后刷新顺序不变；跨组移动为单次原子操作 |
| NAV-04 | 三种展示模式 | 每组独立设定 compact / detail / icon | 切换立即生效并持久化；移动端不溢出 |
| NAV-05 | 固定组布局 | 固定组单列或流式多列，窄屏自动堆叠 | 1~4 个多列组并排不错位；≤900px 单列堆叠 |
| NAV-06 | 首页数据加载 | 一次请求取回全部分组与链接并渲染 | 数百条规模首屏 ≤800ms；失败有错误提示与重试 |
| NAV-07 | 打开行为与安全 | 新标签打开，rel=noopener；协议白名单 | 非法协议不可点；外链均带 noopener noreferrer |
| NAV-08 | 图标策略 | 内置矢量图标集 / emoji / 按域名自动抓取 favicon（服务端代理+缓存） | 抓取失败有兜底且不阻塞渲染；同域名 7 天内不重复外呼 |

### B. 访问控制（AUTH / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| AUTH-01 | 首次设密与登录 | **首次使用即强制设置访问密码**（该密码同时是备份加密口令，故系统中恒不存在无密码实例）；之后需登录才能编辑 | 新实例首个访问者被引导设密，无法跳过；最短 6 位校验与重复输入校验生效 |
| AUTH-02 | 会话管理 | 登录签发有时效 token（建议 30 天）；支持注销与修改密码 | 注销后旧 token 立即失效；改密后其他设备全部下线 |
| AUTH-03 | 访客只读 | **未登录可浏览全部书签，但不能编辑**；写接口一律 401 | 访客态界面上无任何编辑入口；直接调写接口返回 401；读接口稳定可用 |
| AUTH-04 | 登录限流 | 同 IP 连续失败达阈值后锁定一段时间 | 返回剩余锁定时间；限流记录定期清理 |
| AUTH-05 | 编辑锁 | 登录后可切换浏览/编辑模式，浏览模式下隐藏编辑控件 | 状态可持久化；浏览模式下写操作入口不可见 |

### C. 插件快速收藏（CAP / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| CAP-01 | 右键收藏到指定分组 | 右键 → 收藏到 SuenWeb → 分组子菜单（实时取服务端分组） | 菜单与服务端分组一致；无分组时有引导项；服务端不可达给出明确失败提示 |
| CAP-02 | 一键收藏当前页 | 弹窗一键收藏到默认分组（记住上次选择） | 一次点击完成；默认分组可配置 |
| CAP-03 | 收藏结果反馈 | 成功 / 失败 / 已存在三种结果均可见 | 无静默失败；失败原因可读 |
| CAP-04 | 重复识别与合并 | 同 URL 已存在时提示并支持「合并到你选定的分组」 | 不产生重复记录；合并后原记录归属明确 |
| CAP-05 | 新标签页跳转（可选开关） | 开启后新标签页打开导航页 | 开关即时生效；关闭恢复浏览器默认新标签页 |

### D. 插件 ↔ 服务端联动（SYNC / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| SYNC-01 | 插件配置与登录 | 填服务器地址与访问密码，换 token 后本地保存 | 保存前做连通性测试；密码不明文回显；token 失效有自动重登或明确提示 |
| SYNC-02 | 服务端 → 浏览器书签同步 | 把新增/改动过的书签推入浏览器「其他书签 / SuenWeb」 | **推送成功才标记已同步**；任何失败不得提前标记（防书签静默丢失） |
| SYNC-03 | 心跳与在线状态 | 插件定期上报，导航页显示在线/离线与上次通讯 | 在线状态基于真实心跳时间差 |
| SYNC-04 | 实时变更推送 | 导航页改动后插件即时感知并触发同步/备份（SSE 或等价） | 断线自动重连；重连补齐期间变更，不丢事件 |
| SYNC-05 | 变更触发备份 | 书签集合变化时按策略自动备份，短时间多次变更合并 | 3 秒内多次收藏只备份一次；失败下轮重试 |

### E. 导入导出（IMP / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| IMP-01 | 导入浏览器书签 HTML | 上传 Netscape Bookmark HTML，按文件夹名建分组（**同名自动合并**），按归一化 URL 去重 | 导入前出预览（总计/新增/跳过重复）；重复项不入库；同名文件夹合并且不产生重复分组 |
| IMP-02 | 导入 Chrome/Firefox 书签 JSON | 支持浏览器导出的 Bookmarks JSON | 自动识别格式；无法识别给出明确报错 |
| IMP-03 | 导出为浏览器书签 | 下载标准 Netscape HTML，可被任意浏览器导入 | Chrome 与 Firefox 实测可导入且分组正确（Firefox 优先） |
| IMP-04 | 全量配置导出（加密） | 分组+链接+设置+扩展清单导出为**加密文件**（密钥由管理密码派生，见 IMP-06） | 导出文件无法用文本编辑器读出明文；输入管理密码可完整还原 |
| IMP-05 | 全量配置导入（需密码） | 覆盖式恢复：**必须先输入管理密码成功解密**才允许导入；导入前展示覆盖范围并二次确认 | 未填密码或密码错误时拒绝导入且不修改任何数据；失败可回滚 |
| IMP-06 | 加解密与密钥派生 | 密钥 = PBKDF2-SHA256(管理密码, 固定盐) → AES-256-GCM（SWB1 文件格式）；口令与后端管理密码是同一个 | 同一密码在新实例上也能解密同一份导出文件；密码错误时明确提示「密码不正确」而非乱码；文件被篡改校验必失败 |

### F. 备份与还原（BAK / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| BAK-01 | 手动一键备份 | 插件或网页端一键打包「应用全量数据 + 浏览器书签 + 扩展清单」并加密上传 WebDAV | 返回逐项成功/失败明细；部分失败可见可重试；未配置 WebDAV 时按钮明确禁用并提示原因 |
| BAK-02 | 服务端每日自动备份 | **仅当配置了 WebDAV** 时启用：每日自动打包、加密、上传并按份数轮转；未配置则不执行任何备份 | 配置后次日可在 WebDAV 看到当日备份；未配置时无任何备份任务与告警噪音；失败有日志且不覆盖历史好备份 |
| BAK-03 | 备份保留份数 | 轮转删除旧备份（默认保留最近 N 份，N 可配） | 超限自动清理最旧；界面显示当前份数 |
| BAK-04 | 备份列表与还原 | 列出 WebDAV 上历史备份（时间/类型/大小），选任一还原（**需输入管理密码解密**） | 还原前二次确认；密码错误拒绝且不改数据；还原后数据与备份一致 |
| BAK-05 | WebDAV 配置与连接测试 | 地址/用户名/密码 + 连通与写入测试；保存后即被视为开启自动备份 | 区分「连通但不可写」「认证失败」「目录不存在」；保存即显示「自动备份已开启」 |
| BAK-06 | 网页端备份管理入口 | 导航页设置内提供 WebDAV 配置、备份列表、立即备份、下载与还原 | 不依赖插件即可完成备份与恢复闭环 |

## 五、数据模型草案（核心 6 表）

| 表 | 关键字段 | 说明 |
|---|---|---|
| groups | id, name **UNIQUE**, icon, type(fixed/tab), display_mode, layout_mode, sort_order | 名称唯一约束是「重名自动合并」的落地基础 |
| links | id, group_id(FK), title, url, url_normalized, description, icon, icon_type, sort_order, sync_state, created_at | url_normalized 建索引用于去重 |
| settings | key, value | 单表 KV；键集合由一份 schema 定义驱动（读写白名单同源）；含 webdav_url/user/pass、backup_enabled、backup_key_wrapped（包裹后的派生密钥）、backup_keep |
| extensions | id, ext_id, name, version, url, browser, updated_at；UNIQUE(ext_id, browser) | 扩展清单 |
| backups | id, kind, location, size, created_at, status | 备份索引；文件本体在 WebDAV（加密态） |
| sessions | token_hash, created_at, expires_at, device | token 只存哈希；支持按设备注销 |
| dedupe_ignores | url_normalized + group_id（主键）、created_at | 跨组重复的「不再提示」记忆；按 (URL, 目标分组) 粒度，可撤销 |

去重口径统一：入库时写 url_normalized（协议+主机小写、去默认端口、去尾斜杠、去常见跟踪参数、丢 hash、query 排序），判重、导入、收藏均以此为准。
重复分两类处理：**同组重复**（该分组里已有同一 URL）直接静默合并，不提示；**跨组重复**（别的分组已有同一 URL）必须由前端弹窗让用户选择 —— 放行（两组各留一份）／忽略（放行且以后不再提示）／不加（返回已存在那条）。插件收藏与批量导入走同一套口径。
分组名归一化：trim + 连续空白折叠 + 大小写不敏感比较，用于「同名自动合并」。

## 九、备份加密方案（v2 · 简化版，已按决策定稿）

**口令**：复用后端管理密码，不引入第二个 token。管理密码在首次使用即强制设定，因此口令恒存在，没有「无口令」分支。
**密钥派生**：K = PBKDF2-SHA256(管理密码, 固定盐 FIXED_SALT, 100000 次) → 256 bit。固定盐与文件自身盐分离：FIXED_SALT 保证同一密码在任何实例上能派生出同一把密钥，从而支持「导出→另一个部署导入」。
**加密**：AES-256-GCM，文件级随机 IV(12B)；文件结构 = magic("SWB1") + version + fileSalt + iv + 密文 + GCM tag。
**服务端每日任务怎么拿到密钥**：登录/设密/保存 WebDAV 配置时，服务端可获知明文密码一次，此时算出 K 并用服务端密钥（环境变量 BACKUP_WRAP_KEY）包裹后存入 settings；每日 cron 解包得到 K 再加密上传。若未配置该密钥，则退化为直接用设置中的口令校验材料派生（可接受的风险降级，符合「数据价值不高」的定位）。
**加密范围**：WebDAV 备份文件（应用数据 / 书签 / 扩展清单）、全量配置导出的 JSON。
**解密**：导入、还原、下载查看备份内容时要求输入管理密码；GCM 认证失败一律提示「密码不正确或文件已损坏」，且**不写入任何数据**。
**明确不做的严格化措施**：不做 token 独立生成与抄录流程、不做逐文件密钥、不做 KMS/多密钥轮换、不做双重验证。
**改密的影响**：改密即改口令，此前生成的备份无法用新密码解开；无需处理——下一次备份会写入新密钥内容，旧文件随保留份数轮转被淘汰。
