# SuenWeb 2.0 · 功能清单（重构基线 v1.0）

> 用途：本项目清空重建后的**唯一功能参照**。开发任务、提交、PR、验收一律引用本文的功能 ID。
> 状态：待产品裁决（第二章后的「决策点」共 6 条）。
> 说明：每条功能给出「一句话定义 + 验收标准」，不写实现细节；技术选型与目录结构另行成文。

---

## 一、产品定义

**一句话**：自托管的书签服务。书签存在自己的服务端，浏览器插件负责「一键收藏」，导航页负责「多端浏览」，备份与导入导出负责「不丢数据」。

**核心闭环（P0 必须全部打通）**

    浏览器右键/点按 ──► 插件 ──► 服务端书签库 ──► 导航页浏览/搜索
                                      │
                                      ├──► 导入（浏览器书签 HTML / JSON）
                                      ├──► 导出（HTML / 全量 JSON）
                                      └──► 备份（WebDAV / 服务端定时 / 手动）

**边界**：单用户、自部署、零成本优先（Cloudflare Workers + D1 免费额度，或 Docker 自托管）。

## 二、优先级口径

| 级别 | 含义 | 交付要求 |
|---|---|---|
| P0 | 核心闭环，缺任一环产品不成立 | 第一版必须全绿 |
| P1 | 正式可用所必需（安全、稳定性、可迁移） | 第一版收尾前完成 |

| X | 明确不做 | 不排期，不接受需求插入 |

## 三、功能清单（53 项）

### A. 服务端书签核心（NAV / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| NAV-01 | 分组管理 | 新建/重命名/删除分组；两种类型：fixed（固定区，常驻首页）与 tab（标签区，点击切换）；删除分组级联删除其内链接 | 增删改即时生效并落库；删组后其链接全部消失且无法通过任何接口取回；同名分组有明确策略（见决策点 2） |
| NAV-02 | 链接管理 | 新建/编辑/删除链接：标题、URL、描述、图标、所属分组 | 必填校验（标题+URL）生效；URL 非法（非 http/https/mailto/ftp）被拒；编辑后列表即时反映 |
| NAV-03 | 排序与跨组移动 | 分组排序、组内链接排序、链接拖到另一分组 | 拖拽结束顺序即服务端顺序（刷新后不变）；跨组移动为单次原子操作，不出现中间态 |
| NAV-04 | 三种展示模式 | 每个分组独立设定：compact（紧凑列表）/ detail（卡片带描述）/ icon（仅图标） | 切换后立即生效并持久化；三种模式在移动端不溢出 |
| NAV-05 | 固定组布局 | 固定组可选单列或流式多列（多列自动填充），窄屏自动堆叠 | 1/2/3/4 个多列组并排时不错位；≤900px 单列堆叠 |
| NAV-06 | 首页数据加载 | 一次请求取回全部分组与链接并渲染 | 冷启动首屏可用链接 ≤ 800ms（数百条规模）；失败有明确错误提示与重试 |
| NAV-07 | 打开行为与安全 | 链接新标签打开，rel=noopener；协议白名单过滤 | 非法协议（javascript: 等）渲染为不可点；所有外链带 noopener noreferrer |
| NAV-08 | 图标策略 | 支持三种图标来源：内置矢量图标集、emoji、按域名自动抓取 favicon（服务端代理 + 本地缓存） | 自动抓取失败有兜底图标且不阻塞渲染；同一域名 7 天内不重复外呼 |

### B. 访问控制（AUTH / P1）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| AUTH-01 | 首次设密与登录 | 首次使用设置访问密码；之后每次访问需登录 | 未设密码时引导设密；密码强度与重复输入校验生效 |
| AUTH-02 | 会话管理 | 登录签发有时效的访问 token（建议 30 天）；支持注销、修改密码 | 注销后旧 token 立即失效；改密后其他设备全部下线 |
| AUTH-03 | 访客可见范围 | 定义未登录时能看到什么（只读看板 / 完全阻断） | 按决策点 1 执行，接口层与界面层一致，不留绕过路径 |
| AUTH-04 | 登录限流 | 同 IP 连续失败达阈值后锁定一段时间 | 达到阈值返回明确剩余锁定时间；限流记录定期清理不无限增长 |
| AUTH-05 | 编辑锁 | 登录后可切换「浏览模式 / 编辑模式」，浏览模式下隐藏全部编辑控件 | 状态可持久化；浏览模式下任何写操作入口不可见 |

### C. 插件快速收藏（CAP / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| CAP-01 | 右键收藏到指定分组 | 任意页面右键 → 收藏到 SuenWeb → 分组子菜单（实时取服务端分组） | 菜单项与服务端分组一致；无分组时有引导项；服务端不可达时给出明确失败提示 |
| CAP-02 | 一键收藏当前页 | 插件弹窗一个按钮，收藏到默认分组（记住上次选择） | 一次点击完成收藏；默认分组可配置 |
| CAP-03 | 收藏结果反馈 | 成功/失败/重复三种结果都要让用户看见 | 三种结果均有可见反馈，不出现静默失败 |
| CAP-04 | 重复识别 | 收藏已存在的 URL 时提示「已收藏」并给出去重选项 | 同一 URL 不产生重复记录 |
| CAP-05 | 新标签页跳转（可选开关） | 开启后新标签页直接打开导航页 | 开/关立即生效；关闭后恢复浏览器默认新标签页 |

### D. 插件 ↔ 服务端联动（SYNC / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| SYNC-01 | 插件配置与登录 | 插件内填服务器地址与访问密码，换 token 后本地保存 | 保存前做连通性测试；密码不明文回显；token 过期有自动重登或明确提示 |
| SYNC-02 | 服务端 → 浏览器书签同步 | 把「新增/改动过的书签」推入浏览器「其他书签 / SuenWeb」目录 | 推送成功才标记已同步；任何失败不得提前标记（否则书签静默丢失） |
| SYNC-03 | 心跳与在线状态 | 插件定期上报，导航页据此显示插件在线/离线与上次通讯时间 | 在线状态反映真实心跳时间差，不写死 |
| SYNC-04 | 实时变更推送 | 导航页改动后插件无需轮询即可感知并触发同步/备份（SSE 或等价机制） | 断线自动重连；重连后补齐期间变更，不丢事件 |
| SYNC-05 | 变更触发备份 | 书签集合发生变化时按策略自动触发一次备份，短时间多次变更合并 | 3 秒内多次收藏只触发一次备份；备份失败下轮重试 |

### E. 导入导出（IMP / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| IMP-01 | 导入浏览器书签 HTML | 上传 Netscape Bookmark HTML，按文件夹建分组、按归一化 URL 去重 | 导入前先出预览（将导入 N 条 / 新增 M 条 / 跳过重复 K 条）；重复项不重复入库 |
| IMP-02 | 导入 Chrome 书签 JSON | 支持浏览器导出的 Bookmarks JSON | 自动识别格式；无法识别时给出明确报错 |
| IMP-03 | 导出为浏览器书签 | 下载标准 Netscape HTML，可被任意浏览器导入 | 导出的文件在 Chrome/Firefox 实测可导入且分组正确 |
| IMP-04 | 全量配置导出 | 分组 + 链接 + 设置 + 扩展清单导出为 JSON（含版本号） | 导出文件可被同一版本完整导入恢复；敏感密钥处理按决策点 6 |
| IMP-05 | 全量配置导入 | 覆盖式恢复，导入前展示将覆盖的范围并要求二次确认 | 导入过程失败可回滚，不产生半套数据；导入后 id 变化不影响引用完整性 |

### F. 备份与还原（BAK / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| BAK-01 | 手动一键备份 | 插件或网页端一键把「应用全量数据 + 浏览器书签 + 扩展清单」打包上传 | 返回逐项成功/失败明细；部分失败可见且可重试 |
| BAK-02 | 服务端定时备份 | 服务端每日自动全量备份并保留历史 | 备份任务失败有日志与告警；连续失败不覆盖好备份 |
| BAK-03 | 备份保留份数 | 按策略轮转删除旧备份（如保留最近 N 份） | 超过 N 份自动清理最旧的；界面上能看到当前份数 |
| BAK-04 | 备份列表与还原 | 列出历史备份（时间/类型/大小），可选任一还原 | 还原前二次确认；还原后数据与备份时一致；可还原到指定类型（应用数据 / 书签 / 扩展清单） |
| BAK-05 | 存储后端与连接测试 | 支持 WebDAV 作为备份目标，提供连接与写入测试 | 测试区分「连通但不可写」「认证失败」「目录不存在」等原因 |
| BAK-06 | 网页端备份管理入口 | 在导航页设置中提供备份列表、立即备份、下载与还原 | 不依赖插件也能完成备份与恢复闭环 |

### G. 跨浏览器扩展清单备份还原（EXT / P0）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| EXT-01 | 采集与上报扩展清单 | 插件读取本机已安装扩展（排除自身），上报到服务端，记录浏览器类型 | 上报为按浏览器全量替换；字段含 id/名称/版本/商店链接 |
| EXT-02 | 云端清单查看 | 导航页展示已备份的扩展清单，按浏览器分组，同名跨浏览器合并显示 | 能区分 Chrome 与 Firefox 记录；可删除单条 |
| EXT-03 | 一键还原（引导安装） | 与服务端清单比对，找出缺失项并批量打开对应商店页 | 限制一次打开数量（≤10）；显示「已装 X / 打开 Y / 未打开 Z」 |
| EXT-04 | 商店链接规则 | Chrome 用 Web Store 详情或搜索，Firefox 用 AMO 搜索 | 规则集中在一处实现，前后端不重复维护 |

### H. 外观与体验（UI / P2）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| UI-01 | 背景系统 | 纯色 / 渐变 / 图案 / 壁纸（壁纸可自定义源与轮播） | 四模式切换即时生效；壁纸加载失败回落到渐变 |
| UI-02 | 主题 | 多套配色 + 视觉风格（圆角/阴影/模糊/边框），支持一键预设 | 全部视觉由设计 token 驱动，新增一套主题只改 token |
| UI-03 | 字体与字号 | 内置字体 + 自定义 CDN 字体，全局字号缩放 | 字体加载失败回落系统字体，不白屏 |
| UI-04 | Hero 小组件 | 时钟、日期、天气（含城市设置） | 天气失败有占位态；时区/12-24 小时制可配 |
| UI-05 | 响应式与移动端 | 手机/平板/桌面自适应；移动端可完成排序等全部操作 | 360px 宽度下无横向滚动；移动端具备替代拖拽的操作方式 |
| UI-06 | 键盘与快捷操作 | Esc 逐层关闭弹层、Enter 提交、全局聚焦搜索 | 不出现重复绑定导致的多开标签等副作用 |

### I. 智能与治理工具（TOOL / P2）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| TOOL-01 | AI 补全 | 为链接生成简短中文描述、为分组推荐图标；默认免 Key 可用，支持自定义模型 | 失败有降级（启发式规则）且不阻塞用户操作 |
| TOOL-02 | 重复链接检测 | 全库按归一化 URL 聚类，逐组保留一条、其余可批量删除 | 检测与删除前后端字段契约一致，不存在「永远无重复」的假阴性 |
| TOOL-03 | 失效链接检测 | 批量探活，标记失效项并支持清理 | 结果可保存与复查，不必每次全量重跑 |
| TOOL-04 | 操作日志 | 记录管理类写操作，可查最近记录 | 日志有上限与清理策略，不无限增长 |

### J. 运维与分发（OPS / P1）

| ID | 功能 | 定义与要点 | 验收标准 |
|---|---|---|---|
| OPS-01 | 部署方式 | 首选 Cloudflare Workers + D1 一键部署；可选 Docker 自托管 | 两条路径都有逐步可执行的文档，且不依赖本地命令行也能完成 |
| OPS-02 | 插件分发 | 提供 Chrome(.crx/.zip) 与 Firefox(.xpi) 下载，**产物由构建生成，不入库** | 下载到的包可直接安装（或明确说明开启开发者模式）；产物与源码同源可验证 |
| OPS-03 | 健康检查与错误可读 | 健康检查接口；数据库/绑定缺失时返回可操作的中文指引 | 关键故障不出现纯英文堆栈或静默 500 |
| OPS-04 | 数据迁移与升级 | 版本化迁移脚本，升级不丢数据 | 从上一版本升级到新版本可自动完成并保留全部数据 |
| OPS-05 | 质量门禁 | 类型检查 + lint + 关键路径测试进 CI | 任一 PR 破坏类型或关键路径测试则 CI 必红 |

## 四、明确不做（X）

| 项 | 说明 |
|---|---|
| 多用户 / 团队协作 / 分享权限 | 单用户自托管，不做账号体系 |
| 社交、评论、内容推荐流 | 与产品定位无关 |
| 密码管理（保存账号密码） | 仅保存书签，不碰凭据 |
| 原生移动 App | 移动端通过响应式 Web + PWA 覆盖 |
| 自建账号云同步服务 | 备份目标限定为用户自己的 WebDAV 或部署方存储 |

## 五、数据模型草案（核心 6 表）

| 表 | 关键字段 | 说明 |
|---|---|---|
| groups | id, name, icon, type(fixed/tab), display_mode, layout_mode, sort_order | 分组；name 是否唯一见决策点 2 |
| links | id, group_id(FK), title, url, url_normalized, description, icon, icon_type, sort_order, sync_state, created_at | 书签主体；url_normalized 建索引用于去重 |
| settings | key, value | 单表 KV；键集合由一份 schema 定义驱动（读写白名单同源） |
| extensions | id, ext_id, name, version, url, browser, updated_at；唯一键 (ext_id, browser) | 扩展清单 |
| backups | id, kind, location, size, created_at, status | 备份索引（实际文件在 WebDAV / R2 / 本地） |
| sessions / devices | token_hash, created_at, expires_at | token 只存哈希；支持按设备注销 |
| （可选）events / audit | id, kind, payload, created_at | 实时推送与审计，需 TTL 上限 |

去重口径统一：入库时写入 url_normalized（协议+主机小写、去尾斜杠、去常见跟踪参数），判重与导入均以此为准。

## 七、非功能要求

| 类别 | 要求 |
|---|---|
| 安全 | 密钥/token 不明文回显；不提供「密码当 token」等兜底；出网目标（图标抓取、自定义模型、壁纸源）走白名单；插件私钥不入库 |
| 性能 | 千条链接规模下首页首屏 ≤1s、写操作 ≤300ms；列表接口分页或游标预留；避免逐条 SQL 往返 |
| 可靠性 | 导入/还原/备份具备幂等与可回滚；同步失败不得丢书签；定时任务失败可观测 |
| 兼容 | Chrome/Edge 必选（MV3）；Firefox 见决策点 3；导出文件兼容主流浏览器 |
| 可维护 | 单一 schema 来源；前端模块化与状态集中；插件产物由构建生成、单一真源 |

## 九、需要你拍板的 6 个决策点

| # | 决策 | 选项 | 影响 |
