## 通过项（无问题）

- 响应包格式 `{ok, data, error}` 三端一致
- `CROSS_GROUP_DUPLICATE` 409 details 结构三端对齐
- ack 契约「先写书签再 ack」在两条路径均遵守
- SSE 事件名三端一致
- token 生成熵足够（32 字节 base64url）
- sessions 存 hash 不存明文
- PRAGMA foreign_keys=ON + FK CASCADE 正确
