## M2 迭代 1（用户验收反馈，2026-10-23）

| 反馈 | 处理 |

| 卡片太大，收藏多了翻不完 | 尺寸同比例缩小：grid 1/2/3/4/5 列、gap-4、padding p-4、圆角 20px、阴影 5/10px、标题 text-base、描述 text-xs、图标 8px 方块 |

| 页面图标太多 | 顶栏只留品牌标；操作全部收进右下角自动隐藏胶囊：未登录仅「登录」，登录后「编辑锁 / 设置 / 登出」 |
