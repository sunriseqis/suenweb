## 一、产品定位与边界（重构前先对齐，避免范围漂移）

| # | 结论 | 说明 |
|---|---|---|
| 1 | 单用户自托管导航页 + 配套浏览器插件 | 无用户表、无多租户；wallpaper_state / sync_state 固定 id=1 单例 |
| 2 | 主部署形态 = Cloudflare Workers + D1 + Workers AI | 旧 Python/FastAPI 版已归档到 legacy-python 分支，本仓零 Python 代码 |
| 3 | 前端 = 纯静态单文件 SPA，无框架无构建 | templates/index.html 一份承载结构+样式+2300 行脚本；public/ 是它的构建产物（且被提交） |
| 4 | D1 是唯一真源 | 浏览器书签、WebDAV 备份都只是「外挂副本」，当前并非对等双向同步 |
| 5 | 规模假设：链接数百条、单实例、零成本 | 依赖 Workers 免费额度、Workers AI 免费模型、D1 免费额度 |

## 二、现状技术基线（一屏看懂旧架构）

| 层 | 现状 | 重构要点 |
|---|---|---|
| 运行时 | Workers，Hono 4，66 条路由（44 条 requireAuth） | 路由可按域拆分模块；命名纠偏（/api/ai/check 实为链接巡检） |
| 数据 | D1 15 张表；DDL 有**两份**（schema.sql 与运行时 ensureDatabaseTables）且已漂移 | 收敛为单一迁移机制 |
| 鉴权 | PBKDF2-SHA256 + 30 天 Bearer token；登录限流 5 次/15 分锁 30 分 | 保留；修掉「token 当明文密码再验一次」的兜底分支 |
| 前端 | 单 HTML 内联 2300 行 ES5 全局脚本；写操作后全量重拉重渲染 | 拆模块、状态收敛、引入最小构建 |
| 插件 | 同一份 background.js 跑 Chrome MV3 + Firefox MV2 | 决定 Firefox 支持策略 |
| 构建 | 仅 tsc --noEmit，零测试零 lint | 补最小 CI 门禁 |
| 分发 | 插件产物 4 份重复提交（extension/、public/extension/、src/extensions.ts 内嵌 base64、zip 内副本） | 单一真源 + 构建生成 |

**现有数据表（15 张）**：settings / groups_table / links / sync_state / auth_tokens / event_log / operation_log / wallpapers / wallpaper_state / fonts / icon_cache / steamgriddb_cache / ext_repo / auth_rate（仅代码建表）/ backups（仅代码建表）。
